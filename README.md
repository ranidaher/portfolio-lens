# Portfolio Lens

Personal investment portfolio tracker. Tracks public markets (stocks, ETFs, money market funds) and real estate across multiple accounts, countries, and currencies.

## Features
- Multi-account tracking (brokerage + real estate)
- Tax-sheltered vs taxable account filtering
- Trade recording (buy/sell)
- Cash flow tracking (deposits/withdrawals)
- Securities master list with asset class and region
- Multi-currency support with USD base

## Tech Stack
- **Frontend**: Next.js + React
- **Database**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth
- **Hosting**: Vercel

## Setup
1. Create a Supabase project
2. Run the database setup SQL
3. Set environment variables (see `.env.local`)
4. Deploy to Vercel
